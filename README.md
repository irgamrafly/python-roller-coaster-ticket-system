# Python Roller Coaster Ticket System

## Description
This project is a simple roller coaster ticketing system developed using Python. It uses nested conditional statements to determine whether visitors meet the requirements to ride a roller coaster, apply membership discounts, and calculate ticket payments.

## Features
- Age verification (minimum 12 years old).
- Height verification (minimum 150 cm).
- Membership status verification.
- IDR 10,000 discount for members.
- Automatic ticket price calculation.
- Payment verification.
- Automatic change and remaining balance calculation.

## Ticket Information
- Regular ticket price: IDR 50,000.
- Membership discount: IDR 10,000.
- Minimum age: 12 years old.
- Minimum height: 150 cm.

## Technologies Used
- Python 3
- Conditional Statements (if, elif, else)
- Nested If Statements
- User Input and Output
- Basic Arithmetic Operations

## How to Run
1. Make sure Python 3 is installed on your computer.
2. Open the terminal in the project directory.
3. Run the following command:

```bash
python roller_coaster.py
```
